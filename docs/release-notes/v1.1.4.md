# אפליקציה לאנדרואיד
date: 2026-10-29

- אפליקציית אנדרואיד עצמאית (HebrewMaps.apk): השרת רץ בתוך האפליקציה, ואת נתוני המפה מורידים מתוכה (תפריט ← עדכונים), בלי מחשב.
- הקובץ מצורף למהדורה, ונבנה אוטומטית עם כל גרסה חדשה.
- ניווט קולי בעברית: כפתור "התחלת ניווט קולי" במסלול. המפה עוקבת אחריך, מקריאה את ההוראות, ומחשבת מסלול מחדש כשסוטים.
- השרת באנדרואיד רץ בשירות רקע, כך שהורדות ארוכות לא נקטעות.
- מועדפים (לחיצה ארוכה על המפה), הקלטת מסלול עם שיתוף כקובץ GPX, ושיתוף מיקום או פתיחתו באפליקציית מפות אחרת.
- מסך הטעינה באנדרואיד מציג שלבים ושגיאות הפעלה.
